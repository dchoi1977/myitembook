# MyItemBook · CBT 1기

나다운 결을 발견하다 — MyItemBook(MIB) 비공개 테스트(최대 30명, 7일) 웹앱입니다.

- **앱**: GitHub Pages에서 그대로 서빙되는 정적 페이지 (`index.html` + `js/`). 빌드 단계 없음.
- **서버**: Supabase 프로젝트 `MIB CBT` (서울 리전)
  - Postgres + 행 단위 보안(RLS): 내 기록은 나만, 공개 카드는 고른 범위에만, 운영 지표는 운영자만
  - Storage `item-photos` (비공개, 본인 폴더만)
  - Edge Function `mib-api`: 초대 코드 가입, Claude API 중계(1인 하루 한도), 계정 완전 삭제, 운영자 비밀번호 재설정

## 처음 한 번 — 운영자 준비

1. **AI 키 등록**: Supabase 대시보드 › Edge Functions › Secrets › `ANTHROPIC_API_KEY` 추가. 재배포 없이 바로 켜집니다.
   (선택) `ANTHROPIC_MODEL`, `ANTHROPIC_MODEL_QUICK`로 모델을 바꿀 수 있습니다.
2. **운영자 계정**: 앱에서 '초대 코드로 시작하기' → 운영자 코드로 등록 → 상단 톱니바퀴(운영 콘솔).
3. **테스터 초대**: 운영 콘솔 › 초대 코드 › '남은 코드·링크 모두 복사' → 한 사람에 하나씩 전달.
   링크(`…/?code=MIB-XXXXX`)로 들어오면 코드가 자동으로 채워집니다.

> 초대 코드는 이 저장소에 넣지 않습니다. 운영 콘솔에서만 확인하세요.

## 개인정보 원칙

- 원문 기록·해석은 `app_state`에 본인만 읽고 쓸 수 있게 저장 (운영 콘솔에는 횟수만)
- 사진은 해석에만 쓰고 저장하지 않음 (선반 사진만 본인 전용 저장소)
- 공감 숫자는 받은 사람에게만, 순위 없음
- 조회 기록: 친구는 이름, 그 밖은 숫자. '조용히 보기'는 서로 공평하게(나도 이름을 못 봄)
- 내 데이터 › 완전 삭제 = 계정과 모든 행·사진 즉시 삭제
